# Image Verification Guide

## Understanding Image Authenticity

When verifying the authenticity of an image, consider these key aspects:

1. **Metadata Analysis**
   - Check EXIF data for camera details, date, and location
   - Look for signs of editing in metadata history
   - Verify if metadata matches claimed origin

2. **Visual Analysis**
   - Look for inconsistencies in lighting and shadows
   - Check for unusual pixelation or blurring
   - Examine edges of objects for signs of manipulation

3. **Reverse Image Search**
   - Use tools like Google Images or TinEye
   - Check when the image first appeared online
   - Look for different versions or modifications

4. **Context Verification**
   - Compare with other images from the same event
   - Check if weather/lighting matches claimed date
   - Verify if objects/technology shown match the time period

## Best Practices

- Always cross-reference multiple sources
- Document your verification steps
- Consider consulting experts for critical verifications
- Use professional tools when available
- Keep records of your findings
